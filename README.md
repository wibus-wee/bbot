## About BBot

One of the motivations for building an Agent system is to use the Agent itself to develop the system, with the Agent's output directly flowing back into the codebase, creating a self-bootstrapping loop.

In the new era, everyone should have their own Agent, as everyone's workflow is different.

For me, I might prefer an Agent that is more focused on code, wholeheartedly helping me write projects. Maybe the point of extending its capabilities is to make it more free, allowing it to adapt to my coding style, or even to adapt to my way of thinking. 

But in any case, freedom is not the primary goal of building this project, and that's also why I didn't use OpenClaw.

### Structure

The project is structured as a monorepo. It's not a very large project, but I prefer to keep it organized in a monorepo structure for better modularity and maintainability.

There are too many vibe code in OpenClaw, and they are not very well organized, so I want to have a more clear structure for my project. I also want to have a more clear separation of concerns, so that I can easily find the code I need to work on.
